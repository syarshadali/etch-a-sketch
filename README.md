# etch-a-sketch
This is the fourth foundations and the second javascript project of the full stack development course of The Odin Project.

<b>OBJECTIVES:</b>

<p>The most popular "Etch-A-Sketch" is a browser-based sketchpad which tests the HTML, CSS and DOM Manipulation skills by building a dynamic grid of square divs where hovering over the square divs by mouse draws sketch in the sketchpad.</p>

<b>KEY REQUIREMENTS:</b>

<ul>
    <li><b>Grid Creation:</b></li>

    <p>By using javascript loops to dynamically generate a grid of square div elements.</p>

    <li><b>Layout:</b></li>

    <p>Using display: flex and flex-wrap: wrap on the wrapper box to ensure all the div squares pack together neatly.</p>

    <li><b>Etch-a-Sketch Effect:</b></li>

    <p>Adding an event listener to the grid squares that changes their background color when the mouse mouseover or mouseenter events are fired.</p>

    <li><b>Dynamic Sizing:</b></li>

    <p>Including a feature or button that prompts the user for a new grid size (for example inputting 20 for 20 x 20 grid) and clears the board.</p>
</ul>

<b>SKILLS DEMONSTRATED:</b>
<ul>
    <li>Use of Flexbox and its properties in interface layout creation.</li>
    <li>Logging messages in the console of the browser by the use of console.log()     method.</li>
    <li>prompt() method instructs the browser to display a dialog with an optional message prompting the user to input some text.</li>
    <li>The use of Math.random() and the Math.floor() built-in functions to generate random whole numbers.</li>
    <li>Functions are used which are reusable blocks of code designed to perform specific tasks. This is called Modular Programming.</li>
    <li>When we click the buttons in the UI, an event occurs which is tracked by addEventListener() which is the recommended method for adding event listeners.</li>
    <li>The if...else conditional statement to execute different blocks of code based on whether a specified condition is true or false.</li>
    <li>A for loop repeats until a specified condition evaluates to false.</li>
    <li>The increment operator(++).</li>
    <li>Using git for version control and navigating files and directories in Linux system through terminal.</li>
</ul>
